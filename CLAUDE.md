# Second Brain Starter

Shared OKF second brain. Dual-host with Grok Build and Codex.

- Knowledge root: `knowledge/`
- Write helper: `python3 scripts/brain.py write`
- Pack helper: `python3 scripts/brain.py pack --root <title-or-path>`
- Identities: `agents/identities/`
- Packing prompts: `agents/packing/`
- Articles workflow: `agents/articles-workflow.md`

Do not write types owned by another plugin. Do not put real client names here if this clone is public.
